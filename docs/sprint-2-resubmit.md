# Спринт 2. Гипотеза решения

**Направление:** Новый инвестиционный опыт.

## Кому помогаем и что предлагаем

Утренняя сводка по своим выпускам с пут-офертой даёт то, чего нет на экранах приложения.

1. **Последний день, когда брокер ещё принимает поручение.** Это конец приёма у эмитента минус три рабочих дня. На карточке БО-03 `RU000A107A93` показан день расчётов 25 августа 2026. Последнего дня подачи на экране нет: это 11 августа.
2. **Две суммы без совета** и без рекомендации «сдавайте» или «оставляйте»: деньги при выкупе по номиналу и купон до следующей оферты, если бумагу оставить.

Заявку не отправляем. Кнопка «Подать заявку» не является ценностью.

Модель не входит в первую версию. Она появится только если замер 3–5 оферт покажет, что в день сообщения эмитента ставки нет в API.

## Почему не другие направления

- **AI-агент** не подходит. В первой версии модели нет. Если замер её включит, она только достанет ставку из текста и портфелем не управляет.
- **AI для торговых роботов** не подходит. Робот ставит заявки. Здесь торгового действия нет.

## Результат для человека

По каждому своему выпуску с близкой пут-офертой клиент видит последний день подачи и две суммы. Решение и подпись поручения остаются его.

## Ценность для Т-Инвестиций

Пока это предположения, замеров нет.

- Клиент видит день и суммы, которых нет на карточке выпуска. Предположение: доля выпусков, по которым он успевает решить до последнего дня подачи, выше, чем когда на экране только день расчётов.
- Пропущенное окно закрывает выкуп по номиналу. Предположение: клиент, который увидел этот день и две суммы по своим бумагам, реже уводит счёт после такой потери.
- Рекомендации нет и заявки нет. Предположение, не факт: обращений «не успел подать на оферту» станет меньше.
- Затраты первой версии — код и чтение портфеля. Модель не вызывается, пока замер не покажет дыру в ставке.

## Зачем нужен T-Invest MCP

Утром и только на чтение: какие корпоративные облигации лежат на счёте, сколько штук и какая цена. Из этого код собирает список своих выпусков и две суммы. Торговые инструменты не вызываем.

Окно приёма MCP не отдаёт: его нет в `GetBondEvents`. Его берём из календаря Мосбиржи. Последний день подачи считает код.

Подтверждено: оба адреса MCP после сертификатов Минцифры отвечают HTTP 401, токена не было. Имя инструмента в статье команды API одно: `invest_get_portfolio`. Контракт `GetBondEvents` — это API, не список tools MCP.

Если чтения портфеля нет, список перестаёт быть списком своих бумаг и роль MCP пропадает. Если нет цены, день подачи и две суммы из номинала, количества и ставки остаются.
