# Данные

## Источники

| # | Данные | Источник | Формат | Обновление | Ограничения |
|---|---|---|---|---|---|
| 1 | Портфель, позиции, операции | T-Invest API / MCP | JSON | При каждом запуске | Доступ только с согласия пользователя |
| 2 | Купоны, оферты, погашения, амортизации | T-Invest API, MOEX ISS | JSON | Раз в сутки | Даты оферт и новые ставки купонов иногда появляются позже, чем существенный факт |
| 3 | Дивиденды и даты отчётности | T-Invest API, MOEX ISS | JSON | Раз в сутки | Даты отчётности часто предварительные |
| 4 | Существенные факты эмитентов | e-disclosure.ru, сайты эмитентов | HTML / PDF | Каждые 10-15 минут | Нет единого удобного API, часть сообщений только в PDF |
| 5 | Документы для RAG: условия выпусков, отчётность | e-disclosure.ru | PDF | При появлении | Сканы и таблицы в PDF требуют аккуратного парсинга |

| 7 | Котировки и объёмы | T-Invest API | Свечи | Ежеминутно | Для неликвидных облигаций мало сделок, сигналы по цене шумные |
| 8 | Фидбек пользователей | Своя БД | Таблицы | Постоянно | На старте его нет |

## Справочник инструментов

Все записи привязываются к инструменту по ISIN и FIGI. Справочник строится из T-Invest API и MOEX ISS: эмитент, тип бумаги, параметры выпуска, ближайшие события. Для новостей без явного тикера привязка идёт по названию эмитента и его вариантам написания.

## Разметка

Готового датасета важности событий нет, поэтому размечаем сами:

- 600-800 событий за 6-12 месяцев по 100-150 бумагам;
- три класса: «требует действия», «важно знать», «фон»;
- два разметчика независимо, расхождения решаются обсуждением;
- для класса «требует действия» дополнительно фиксируется дедлайн и тип действия.

Эта же разметка используется для оценки классификатора и как стартовая обучающая выборка для скоринга.

## Персональные данные

- Портфель читается только с явного согласия пользователя и только в объёме, нужном для ленты.
- Модель развёрнута на своей инфраструктуре, данные портфелей не уходят во внешние LLM API.
- Для эксперимента используются модельные портфели, реальные данные клиентов не нужны.
