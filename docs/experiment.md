# Первый эксперимент

## Гипотеза

AI-триаж находит события, требующие действия по портфелю, лучше простых правил и при этом сильно сокращает число уведомлений.

## Данные

- События за 6-12 месяцев по 100-150 бумагам: облигации и акции, с разной ликвидностью и кредитным качеством.
- 20 модельных портфелей разного состава: облигационные, смешанные, концентрированные.
- 600-800 событий размечают вручную два разметчика по классам «требует действия / важно / фон» (см. [data.md](data.md)).

## Что сравниваем

| Вариант | Как строится дневная лента |
|---|---|
| (а) Хронология | Все события по бумагам портфеля подряд, как в обычной ленте |
| (б) Правила | Ключевые слова в тексте и пороги изменения цены |
| (в) AI-триаж | Классификатор на LLM + скоринг по доле бумаги и срочности |

## Метрики

| Метрика | Роль |
|---|---|
| **recall@5** | Основная: доля событий «требует действия», попавших в топ-5 дневной ленты портфеля |
| Уведомлений в день на портфель | Проверяет вторую часть гипотезы: шума должно стать меньше |
| Доля ошибочных объяснений | Ручная проверка карточек: факт, срок и бумага указаны верно |
| Точность классификатора по типу события | Диагностика: где именно ошибается LLM |

## Порог успеха

- recall@5 ≥ 0,9;
- на 20+ п.п. выше, чем у правил;
- не более 5% ошибочных объяснений при ручной проверке.

## Порядок

1. Собрать события по выбранным бумагам и построить справочник инструментов.
2. Разметить выборку двумя разметчиками.
3. Прогнать три варианта на одних и тех же днях и портфелях.
4. Посчитать метрики, разобрать пропуски критичных событий по одному.
5. Проверить вручную объяснения в карточках на случайной выборке.
